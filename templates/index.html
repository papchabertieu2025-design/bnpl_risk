How it works

A logistic-regression model trained on 1,000 synthetic BNPL customers (76% accuracy on test data). More open plans and a higher balance raise the risk; a higher income lowers it. Risk bands: Low < 30%, Medium 30–60%, High ≥ 60%.

API

Other applications can call the same model and get JSON back:

GET /api/predict?number_of_active_plans=5&monthly_income=1200&outstanding_bnpl_balance=2200
